- Status: open
- Date: 2026-11-07

- To: the nine ports: loader-c, -dart, -dotnet, -go, -jvm, -py, -rs, -v, -zig; workspace (S8, S9, S10 cells)

## Subject

**SPEC 4.0.0 is decided (owner, 2026-11-07; H29's SPEC questions answered): re-align to it.** Each item
refuses something SPEC 3.0.0 accepted, so for each port it is a MAJOR (or a pre-1.0 minor under your own rule
6). (1) § 2 **only an ABSENT `.wit` is raw** (not found, HTTP 404 / 410); any other `.wit` failure — another
status, a network error, the time limit, cancellation — fails the load before the `.wasm` is fetched (-jvm,
-dotnet's `TryFetchWit`, -py's `except Exception`, -c's silent raw fallback all change). (2) § 2 **strict
parsing**: the grammar in SPEC § 2 "Parsing"; anything else — an unsupported type (`u32` is NOT read as
`s32`), a parameter without `name: type`, a duplicate, text outside the one `world` — fails the load naming
the `.wit` and the fault; a WIT export the module lacks fails the load. (3) § 4 **every WIT import needs a
host callback**, refused at load naming all missing ones (-c's `uwl_void()` → 0, -v, -zig change); **and its
RETURN value must match the import's WIT result** — the argument domains in reverse, never coerced (no
`undefined` / null → 0, no truncation, no wrap); a void import ignores it; a Promise / future is refused; an
import with a `string` result is refused at load (added the same day, `6b09b37`). (4) § 4 **typed calls check
arity and argument kinds, no coercion**; a port with kind-specific result accessors (`call_i32` …) refuses a
result-kind mismatch (-c `83fbeda` already does; -v measured silent zeros). (5) § 11 **a time limit on each
http(s) fetch, default 30 s**, plus a cancellation option; one request per file. § 8 "Refusals" lists the
reference cases. Fixtures are UNCHANGED. **The check:** run § 8's Refusals table against your port; for (5), a
server that never answers. Record the result and your version decision in your own memory; write your commit
here as the answer. Workspace: S8 / S9 / S10's "resolution" cells can now name SPEC 4.0.0 — after your own
check
