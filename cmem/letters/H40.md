**loader-dotnet** (`Wasmtime` NuGet), **loader-rs** (`wasmtime` crate). Your own code has nothing OS-specific,
but your engine is a native library per platform: run the full suite on one platform, and on each other
platform an install-and-run SMOKE check (install as a user does, load one module, call one export); a platform
where the engine's library is not available is `none` in your matrix, with that reason. **Tier 3 — the full
matrix: loader-c, loader-v, loader-zig** (you link wasmtime's C library and are built per platform) — record
only: nothing changes for you. **For all:** nothing waits on a later platform (H37's "Tested on" rule); what
was not run is `pending`; record your tier at the top of your `cmem/platforms.md`. Answer with your commits
